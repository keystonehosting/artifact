# M0 — Foundation (v0.1.0)

## What shipped
- **Repos.** `keystonehosting/TEMP` holds the closed references under `artifact/` (ai-toolbox, youraiscroll, ace-build, userscripts) and is not modified after that commit. The public repo is `keystonehosting/artifact`.
- **Clean room.**
  - Leak check runs as a pre-push hook. It is verified to block a planted 200-character slice of a closed file and a planted closed-tool hostname.
  - It subtracts open material (the ACE import, runtime dependencies, license texts, and reviewed interop facts such as Google's AI Studio RPC URL).
- **Analyst pass.** Two isolated subagents wrote `docs/dossier/`:
  - AI Toolbox: 22 feature files plus `endpoints.md` and a 1,965-entry string parity source, by hashed ID only;
  - YourAIScroll: 7 files plus `endpoints-youraiscroll.md`;
  - My Prompt: mechanisms only.
  
  After it landed, the main session found verbatim UI phrases quoted in the dossier and paraphrased about 100 of them. It also rephrased three lines that reproduced code expressions. Both runs of the leak check printed ok.
- **ACE import.** ACE 1.22.0 at `671dfc8` went in as one commit without history, then was restructured into the TypeScript core plus adapter layout. ACE's site parsers live in `decant-core`, which is AGPL-3.0, so they are not used (D1).
- **Archive schema v1.** Zod in `src/core/schema/archive.ts`, published as `schemas/artifact-archive-v1.json`; a test keeps the two identical. It extends ACE export-v1 (`source_ace`, flat `activeBranch`).
- **Zod payload schemas** for ChatGPT, Claude and Grok, plus the Google batchexecute envelope decoder. The decoder was tested against ACE's captured Gemini `hNvQHb` response.
- **Tier 1 adapters** for ChatGPT, Claude, Gemini, AI Studio and Grok:
  - DOM fallback reading through a shared `BaseAdapter`;
  - composer fill and submit (ported from ACE);
  - navigation and streaming detection;
  - health tracking and Self-test.
- **Popup:** export Markdown, text and JSON, copy Markdown, run Self-test and copy the diagnostics. There is also a right-click "export as Markdown" in the background.
- **CI** (typecheck, lint, unit, e2e, three builds) and a **release pipeline** that cuts the tag and pre-release from CI, because the session cannot push tags (D4).

## Tests
- **Unit (Vitest):** 34 tests in 8 files, all passing. They cover:
  - branch walking with forks, cycles and dangling parents;
  - HTML to parts (lists, tables, code language, KaTeX, images);
  - DOM readers on the ChatGPT, Claude, Gemini and Grok captures and a synthetic AI Studio page;
  - Markdown, text and JSON exports (Markdown has a snapshot);
  - archive round-trip and schema sync;
  - filenames, the batchexecute envelope, health and diagnostics redaction.
- **E2E (Playwright, built extension in Chromium):** 6 tests, all passing. The content script reads each Tier 1 fixture page served at the real URL, and Self-test reports its per-check results. All other network traffic is blocked.
