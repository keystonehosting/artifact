# M4 report — Export, backup, lifecycle and Tier 2 (`v0.5.0`)

## What shipped
- **Tasks page** (`tasks.html`) for long jobs, with progress, pause, stop and a downloadable log (CSV and JSON). It keeps running when the side panel closes.
- **Bulk export** (`src/core/bulk/export-job.ts`, `zip-sink.ts`): any scope (all, a site, a folder tree, a project, a selection) as one ZIP laid out by folders, site or flat. Up-to-date stored copies are used; other chats are read from the site in a tab (`site-tabs.ts`, an open tab is reused, a background one is opened and closed otherwise). Each chat is retried twice; files and artifacts come along; JSON for restore beside each chat; `EXPORT_REPORT.txt`; streaming to disk with the File System Access API where available. Projects bring their instructions, knowledge files and memory.
- **Bulk actions** (`action-job.ts`): archive, unarchive, delete, with the full list, typed confirmation above 10 (`delete 23`), one chat at a time with a 1.2 s gap on top of the site's rate limiter, pause and stop, and a log. Sites without the action are skipped and logged.
- **Auto-archive rules**: days untouched, except pinned, except filed; a daily count and notification; the review page starts an ordinary archive job.
- **Deep Import and restore** (`src/core/importers/official.ts`): ChatGPT and Claude `conversations.json`, Google Takeout `MyActivity.json`, and Artifact archives, from a ZIP or JSON, previewed before writing, optionally into a new folder, with library and settings restore.
- **Backups** (`src/core/backup/`): new and changed chats as Markdown and JSON plus `library.json`, hourly, daily or weekly, to Downloads/Artifact Backup (silent, background) or a chosen folder (notification, D28); "everything in one file".
- **Vaults** (`vault.html`): artifacts with versions, previewed in the extension sandbox page (`render.html`, Mermaid 11.17.2) and downloadable as real files, single or all versions; images from every site, previews and bulk download through the sites with the user's session; code snippets by language with copy and Mermaid rendering.
- **Tier 2** (`src/adapters/tier2/`): eight sites with the dossier's selectors, chat ids from the page path, health that says when reading isn't available (D25), Settings switches that request host access and register the content script dynamically (`syncTier2Scripts`).
- **Side panel**: a Data tab; export, archive and delete from the Folders tab; Vault links in the Library tab.
