# M2 report — Organize and search (`v0.3.0`)

## What shipped
- **Library database** (`src/core/db/db.ts`, Dexie): chats, conversations, folders, folder items, tags, Smart Tag rules, labels, bookmarks, highlights, notes, reminders, favorites. The background is the only writer (`src/core/library/api.ts` over `lib:call`), and it tells open views and site tabs to refresh after each change (`lib:changed`).
- **Indexing:** every chat the user opens is stored after replies settle (`features/library/indexer.ts`). A page-text read never replaces a stored structured copy.
- **Search** (`src/core/search/engine.ts`, MiniSearch): one document per message on every branch; filters for role, site, model, dates, folder, tag, exact phrase, titles only, must-include (all/any) and exclude. Side panel Search tab with results grouped by site, highlighted snippets, jump-to-message and a Markdown findings report.
- **Deep scan** (`features/library/deepscan.ts`): lists the site's chats page by page, fetches only new or changed ones, saves state after each step, pauses while the user types or a reply streams. Start, resume, restart, stop and progress in the Search tab.
- **Folders** (`src/core/library/folders.ts`, `src/ui/FolderTree.tsx`): nesting to any depth with cycle refusal, counts (direct and total, de-duplicated), colors, sort modes, pins, stars, breadcrumbs, drag and drop (chats, folders, and chat links dragged from the site's own list). The tree is mounted at the top of the sidebar on ChatGPT, Claude, Gemini and Grok (D19 for AI Studio), and in the side panel with All / Unfiled / Pinned / Archived views and multi-select filing. Projects import as folders, and their stored chats are filed.
- **Pins and favorites:** pinned chats sort first everywhere; GPTs, Gems and projects can be starred as favorite assistants.
- **Tags:** manual tags, seven built-in keyword rules, custom rules (any/all, title/messages, per site), cross-site tag view, rename and delete.
- **On every message:** a margin toolbar to bookmark (with color) and label (multiple colors). Selecting reply text offers five highlight colors; highlights are re-found by quote and context and painted with the CSS Custom Highlight API (D16).
- **Chat notes, continue-later reminders** (alarm every minute, notification opens the chat), **find in chat**, **privacy blur**, and browser commands for both.
- **Side panel:** Folders, Search and Library tabs (bookmarks, highlights, labels dashboard, notes, reminders, tags and rules), and a "This chat" card on the Dashboard (pin, tags, folders, note, reminders, find, blur).
- **Settings:** switches for storing chats, the sidebar tree, the message toolbar, highlights, find and blur.

- End-to-end (Chromium with the built extension, fixtures only): 18 tests. New in `e2e/library.spec.ts`: an opened chat is stored and found by a word on a hidden branch; the sidebar tree mounts in the site's `nav` and shows a folder; bookmark through the margin toolbar; highlight a selection and see it painted; find steps through matches and blur toggles by hotkey and by message; side panel creates a folder, searches with highlighted results, and lists a bookmark.
- The tests found and fixed one bug: re-applying Smart Tag rules wrote inside a read-only cursor.
