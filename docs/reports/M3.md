# M3 report — Prompts, chat experience and cross-AI (`v0.4.0`)

## What shipped
- **Prompt templates** (`src/core/prompts/template.ts`, `docs/prompts.md`): text fields with defaults and hints, single and multiple choice with an "Other" box, hidden and fixed values, file slots, date, time and selection, escapes, and removal of lines left empty.
- **Library** (`src/core/prompts/service.ts`, database v2): prompts, chains, prompt files, prompt history (300 per site), the last 20 handoffs, and drafts. Import and export as JSON or plain text. Prompt of the day from the user's own library.
- **Starter pack**: 44 prompts from the CC0 `prompts.csv` of awesome-chatgpt-prompts, pinned to a commit and recorded in `THIRD_PARTY_NOTICES.md`.
- **In the page** (`src/features/prompts/`): the `//`, `..` and `@@` picker; the variables form; the chain and queue runner with pause, stop, retry and "wait for me" steps; prompt history on the arrow keys; Ctrl/Cmd+Shift+Enter to queue; the enhancer in current-chat mode with a word diff; the profile button on new chats; draft autosave with offline and expired-session notices; and a composer bar in normal flow above the meter that shows run progress and a word count.
- **Chat experience** (`src/features/experience/`): wide mode, speed mode (`content-visibility`), the timeline rail, collapsible messages, RTL, code-block and formula copy, auto-continue, and the reply-finished notification and chime.
- **Cross-AI**: `src/core/crossai/carry.ts` (Local handoff, current-chat request, seed, `@@` blocks), `hub.ts` in the background (text waiting for a new tab's composer, broadcast jobs, right-click prompt menu, notifications), the compare page, and the meter warning's "Continue in a new chat".
- **Side panel**: Prompts tab (prompts, chains, queue, history, files), Cross-AI tab (handoff, broadcast, recent handoffs), the branch map and diff on the Dashboard, and settings for prompts, enhancer presets, profile and chat experience.

## Tests
- Unit: 118 tests. New: templates (every construct, and every starter prompt renders), diff, Local handoff and budget shrinking, mention blocks, the prompt service (validation, sorting, starter import, export/import round trip, history, handoff cap, prompt of the day, drafts), trigger parsing, enhancer helpers, and the runner (step order, "wait for me", stop, queue, timeout).
- End-to-end: 34 tests. New: `//` with a variables form, a two-step chain that waits for each reply, the queue from the panel and the hotkey, prompt history, a draft surviving reload, `@@` mention, a prompt on selected text, starter prompts from the panel, the branch map and diff, handoff to Claude (text waiting, not sent), a Local handoff built in the panel and opened on another site, broadcast with the compare page, wide mode on and off, timeline and collapse-all, auto-continue, and speed mode. They run on a new interactive fixture (`tests/fixtures/synthetic/chat-sim.html`) served at ChatGPT and Claude URLs.
- Bugs the tests found and fixed: a new tab could ask for its pending text before it was stored; settings changed while a page was starting were ignored; on slow loads the first read fetched the chat again instead of using the page's own request (this also failed CI on v0.3.0).
- E2E now blocks DNS in the test browser (D24).
