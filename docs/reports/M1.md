# M1 — Tier 1 adapters, health, meter and usage, side panel, settings, export (v0.2.0)

## What shipped
- **Adapters (ChatGPT, Claude, Gemini, AI Studio, Grok).** Data source order per SPEC §5:
  1. page-world hook copies (`page-hook.content.ts`);
  2. the site's own endpoints with the user's session, paced by a per-site rate limiter that honors `Retry-After`;
  3. DOM text, labelled approximate.

  The normalizers keep the full branch tree, plus:
  - ChatGPT canvases, with each update re-applied as a new version;
  - Claude artifacts (create, update, rewrite) and created files (`create_file`, `str_replace`, `present_files`);
  - Gemini reply drafts as sibling branches;
  - AI Studio thinking chunks.

  Also listing, projects/Gems, and delete/archive/rename where supported. ChatGPT and Claude detect the plan.
- **Health:** every structured read is Zod-validated; a mismatch records a failing check with the reason and the site shows Degraded.
- **Meter:**
  - `o200k` tokens counted in a worker: an offscreen document on Chrome/Edge, the background page on Firefox;
  - the pill, hover breakdown, heaviest messages, sparkline, badges, draft tokens and threshold warnings;
  - calibration from AI Studio's own counter;
  - limits only from `limits.json` (with sources), the site, or the user; otherwise "unknown".
- **Usage:** Claude (endpoint plus stream frames), Gemini (`jSf9Qc`), and the ChatGPT caps widget with a heatmap from the local send log.
- **Export:**
  - Markdown, text, JSON, HTML, DOCX, PDF (print) and PNG (1× and 2×, sliced past the canvas size limit);
  - ZIP bundles with real files, artifacts (every version), canvases and Claude project files, plus `MISSING_FILES.txt`;
  - selected messages, branches, numbering, a table of contents, dates, thinking, tools and the credit line;
  - filename patterns, Obsidian, the preview tab, copy as Markdown, context menu and keyboard commands.
- **Side panel** (Dashboard, Export, Settings), options page, popup quick export.

## Tests
- **Unit:** 67 tests in 12 files, all passing. They cover:
  - normalizers for all five sites; Gemini against ACE's real captured `hNvQHb` response;
  - limits lookup, meter math, calibration, the rate limiter, the URL allowlist and hook capture patterns;
  - HTML (snapshot), DOCX package structure, ZIP bundles with files and failures, Obsidian URIs, and HTML sanitization (under jsdom).
- **E2E (built extension in Chromium):** 12 tests, all passing:
  - content scripts read every Tier 1 page;
  - the page hook captures the page's own conversation request (intercept), including files and canvases;
  - the side panel exports a ZIP containing the real uploaded PDF, the generated PNG, and the canvas with its versions. The bytes travel through the adapter, the background and Playwright-served file hosts;
  - the meter pill appears in flow above the composer and shows "unknown" when no limit is known;
  - draft tokens update while typing;
  - health degrades with a reason when the data endpoint is blocked;
  - Self-test reports its checks.

During this milestone the tests caught that DOMPurify returns its input unchanged where it isn't supported. HTML sanitization now fails closed: it escapes everything when no sanitizer is available.
